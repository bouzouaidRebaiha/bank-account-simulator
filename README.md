# 🏦 Bank Account Simulator

A simple Python program that simulates a basic bank account. Users can check their balance, deposit money, withdraw money, and exit the program.

## Features

* Check account balance
* Deposit money
* Withdraw money
* Validate withdrawal amounts
* Prevent withdrawing more than the balance
* Menu system
* Exit the program

## Concepts I Practiced

* Variables
* `while` loops
* `if / elif / else`
* Functions
* Parameters
* `return`
* Input validation
* Updating variables
